## 題庫與公平性

- 完整採用來源文件 12 題，A 組 5 題、B 組 7 題。尚無圈選結果，因此不自行縮成 10 題。
- 問句逐字保留；只附加相同的繁體中文、公開網路查詢、提供來源與不捏造要求。
- 每題獨立，不帶歷史對話，也不將 AQUASKY 或官網注入 A 組提示。
- 不做網站白名單，不預先餵官網內容；避免把強迫引用當成自然被發現。
- 這是「要求查詢來源」的 API 觀測；不等同消費者產品預設對話。
- 品牌字詞偵測不是推薦判斷；需閱讀原回答確認正負評價、是否真在推薦名單。
- 官方引用只認結構化來源中的 aquaskyplus.com。Google 搜尋跳轉透過 HEAD 查核 Location，保留原始及解析後網址；未能解析者明確標示，官網引用數僅為已確認下限。
- B 組不能只用提及率判斷正確性；認證、測試數字、MOQ、交期與保固需人工核對。
- 六家完整一輪是 72 個問答單元，不預先宣稱全部成功。成功／失敗與實際模型名稱以各執行目錄為準。
